# Project submission is terminal-first via the Crow Submit Skill

The primary — and for MVP the only — way to submit a Project to Crow is through the `/crow-submit` Claude Code skill running in the terminal. The design goal is zero context-switching: a developer finishes building, runs the skill, and their project is live on the Grid without ever opening a browser.

A web submission form was considered and deferred to Phase 2. The existing `submit_new_build` UI prototype remains as a reference for that future work.
